# Interactive Parameterized Cache Simulator & Systems Programming

A comprehensive C++ systems engineering repository implementing a parameterized Cache Architecture Simulator alongside core memory management models, custom allocators, and Object-Oriented Programming (OOP) concepts.

## Key Features
- **Cache Architecture Simulator:**
  - Configurable parameters: Cache Size, Block Size, and Associativity.
  - Replacement Policies: LRU (Least Recently Used), FIFO, and Random eviction modes.
  - Performance Metrics: Hit/Miss tracking, set index decoding, and memory address tag evaluation.
- **Systems Programming & Memory Management (`cpp_labs/`):**
  - Safe memory allocators, pointer manipulation, and leak detection.
  - Standard Template Library (STL) benchmarking and custom data structures (Stacks, Queues, Linked Lists).
  - Advanced OOP: Move semantics, copy constructors, operator overloading, and RAII principles.

## Directory Structure
- `src/`: Core simulator implementation (`cache_simulator.cpp`)
- `cpp_labs/`: Systems C++ labs covering memory management, STL, and OOP design.

## Tools & Compiler
- C++17 / C++20
- GCC / G++ (Ubuntu Linux)
- VS Code
